# Life Organizer

Личный PWA-органайзер: заметки, рутина, задачи и канбан проектов. Только фронтенд (React + Vite), данные хранятся в `localStorage` браузера.

## Экраны

- **Главная** — три прокручиваемых (и сворачиваемых) списка: заметки, рутина, задачи.
  - Рутина: отмеченная задача уходит вниз до конца дня, в начале нового дня (время настраивается) снова открыта.
  - Задачи: свои задачи + первая открытая задача каждого проекта в статусе «В процессе».
- **Проекты** — канбан: Открытые / Бэклог / В процессе / Ожидание / Готово. Проекты из «Готово» уходят в архив через 7 дней. Фильтр по сферам жизни.
- **Проект** — название, статус, сфера, описание, задачи (открытые, затем выполненные).
- **Настройки** — сферы жизни, время начала дня, экспорт/импорт JSON.

Тап по тексту — редактирование (Enter — сохранить, Esc — отмена, 🗑 — удалить). Списки сортируются за ручку ⋮⋮, карточки проектов — перетаскиванием (на телефоне долгим нажатием).

## Разработка

```sh
npm install
npm run dev
npm run build
```

## Деплой

Workflow `.github/workflows/deploy.yml` собирает и публикует сайт на GitHub Pages при пуше в `main`.
Один раз нужно включить: Settings → Pages → Source: **GitHub Actions**.
