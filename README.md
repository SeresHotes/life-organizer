# Life Organizer

Личный PWA-органайзер: заметки, рутина, задачи и канбан проектов. Только фронтенд (React + Vite), данные хранятся в `localStorage` браузера.

## Экраны

- **Сегодня** (главная) — только то, что выбрано на сегодня. Кнопки: «+ Задача» (сразу на сегодня; можно сделать рутиной, выбрав интервал повтора), «+ Мысль» и «Выбрать» — отметить задачи и рутину на день из своих и из проектов в «Бэклог» и «В процессе». Отметка выполнения закрывает саму задачу/рутину. Невыполненное на следующий день не переносится. Стрелки ‹ › листают прошлые дни — только те, где что-то было выбрано; невыполненное оттуда можно вернуть «На сегодня».
- **Задачи** — все задачи и рутина. На телефоне — аккордеон, на компьютере — две колонки. Новый элемент — кнопка «+» у названия списка.
  - Рутина: у каждой свой интервал повтора (1ч, 6ч, 1–7 дней). Отмеченная уходит вниз, справа видно, через сколько вернётся (18ч, 3д). Дневные интервалы считаются от начала дня (время настраивается). Здесь же рутина проектов из «Бэклог» и «В процессе».
  - Задачи: свои задачи + первая открытая задача каждого проекта из «Бэклог» и «В процессе».
- **Мысли** — мысли и заметки; их можно убрать в архив (кнопка слева), архив — внизу списка.
- **Проекты** — канбан: Открытые / Бэклог / В процессе / Ожидание / Готово. Проекты из «Готово» уходят в архив через 7 дней. Фильтр по сферам жизни.
- **Проект** — название, статус, сфера, описание, задачи и рутина проекта.
- **Сферы** — список сфер жизни. Сфера показывает свои проекты, задачи, рутину, заметки, а также завершённое и архив. Сферу можно назначить заметке, задаче, рутине (при редактировании) и проекту.
- **Настройки** — время начала дня, экспорт/импорт JSON.

Тап по тексту — редактирование (Enter — сохранить, Esc — отмена, 🗑 — удалить). Элементы списков и карточки проектов перетаскиваются: мышью — просто тянуть, на телефоне — долгое нажатие.

## Разработка

```sh
npm install
npm run dev
npm run build
```

## Деплой

Workflow `.github/workflows/deploy.yml` собирает и публикует сайт на GitHub Pages при пуше в `main`.
Один раз нужно включить: Settings → Pages → Source: **GitHub Actions**.
