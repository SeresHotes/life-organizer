# Life Organizer

Личный PWA-органайзер: заметки, рутина, задачи и канбан проектов. Только фронтенд (React + Vite), данные хранятся в `localStorage` браузера.

## Экраны

- **Сегодня** (главная) — сверху заметки (всегда под рукой, «+» — новая, архив внизу блока), ниже — только то, что выбрано на сегодня. Кнопки: «+ Сегодня» (новая задача сразу в план дня; можно сделать повторяющейся, выбрав интервал), «+ Задача» (в общий список, не на сегодня), «+ Мысль» и «Выбрать» — отметить задачи на день из своих и из проектов в «Бэклог» и «В процессе». Отметка выполнения закрывает саму задачу. Невыполненное на следующий день не переносится. Стрелки ‹ › листают прошлые дни — только те, где что-то было выбрано; невыполненное оттуда можно вернуть «На сегодня».
- **Задачи** — один общий список: свои задачи, первая открытая задача каждого проекта из «Бэклог» и «В процессе» и повторяющиеся задачи (рутина), свои и этих проектов. Новая задача — большая кнопка «+ Задача» внизу экрана; если выбрать интервал повтора (1ч, 6ч, 1–7 дней), она будет повторяться. У повторяющейся задачи справа виден период (↻1д, ↻6ч); отмеченная уходит вниз, и рядом с периодом видно, через сколько она вернётся (↻1д · 18ч). Дневные интервалы считаются от начала дня (время настраивается).
- **Мысли** — мысли (новая — кнопка «+ Мысль» внизу); их можно убрать в архив (кнопка слева), архив — внизу списка.
- **Проекты** — канбан: Открытые / Бэклог / В процессе / Ожидание / Готово. Проекты из «Готово» уходят в архив через 7 дней. Фильтр по сферам жизни.
- **Проект** — название, статус, сфера, описание, задачи и рутина проекта.
- **Сферы** — список сфер жизни. Сфера показывает свои проекты, задачи, рутину, заметки, а также завершённое и архив. Сферу можно назначить заметке, задаче, рутине (при редактировании) и проекту.
- **Настройки** — время начала дня, экспорт/импорт JSON.

Тап по тексту — редактирование (Enter — сохранить, Esc — отмена, 🗑 — удалить). Элементы списков и карточки проектов перетаскиваются: мышью — просто тянуть, на телефоне — долгое нажатие.

## Разработка

```sh
npm install
npm run dev
npm run build
```

## Деплой

Workflow `.github/workflows/deploy.yml` собирает и публикует сайт на GitHub Pages при пуше в `main`.
Один раз нужно включить: Settings → Pages → Source: **GitHub Actions**.
